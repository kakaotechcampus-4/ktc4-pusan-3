## 1. 연결 형태 네 가지

| 형태 | 언제 | 예 | 저장 |
| --- | --- | --- | --- |
| **상수 파일** | 값이 고정이고 판정에 쓰인다 | 검진 주기 · 접종 일정 · 섭취기준 · 알레르기 19종 | `reference/<출처>_<연도>.*` (코드와 함께 배포) |
| **캐시 테이블** | 값이 크고 재사용된다 | 메뉴 영양·재료 · 도서 · 급식 | DB 테이블 + 야간 배치 |
| **실시간 호출** | 지금 값이어야 한다 | 날씨 · 대기질 · 응급실 · 장소 | 저장 안 함 (프로세스 캐시만) |
| **문서 행** | 서술이 필요하다 | 이유식 안내 · 루틴 전략 · 병원 가야 할 때 | `*_doc` ([`RAG_plan.md`](RAG_plan.md)) |

**규칙**
- Agent는 API를 직접 부르지 않는다. **포트(Protocol) → `app/integrations/` 어댑터**를 거친다.
- 외부 쿼리에 보호자 발화를 넣지 않는다. 닫힌 enum·정규화 키만.
- 응답 스키마가 바뀔 수 있으므로 어댑터가 **내부 dataclass로 변환**해서 넘긴다. 원 응답이 Agent까지 오지 않는다.
- 상수 파일에는 `source`·`version`·`fetched_at`을 함께 둔다. 출력에 기준 버전을 표시한다.
- 라이선스(공공누리 유형)는 도입 전에 확인하고 `sources.yaml`에 적는다.

| NEIS 급식식단정보 (open.neis.go.kr) | 캐시 → `daycare_meal` | 학교·해당 유치원 | 어린이집 미포함 |
| 지역 **어린이급식관리지원센터** 표준식단 | 캐시(수동 적재) | 참고 식단 · 카탈로그 보강 | 라이선스 센터별 확인 |

| 실패 | 동작 |
| --- | --- |
| 영양·레시피 API 장애 | 캐시만 사용. 미스는 `unresolved` → 기록 행 수에서 빠짐 |
| 7일 10행 미만 | `nutrient.insufficient` 안내 |

## 7. 어댑터 계약

```
app/agents/<domain>/store/ports.py   Protocol (Agent가 소유)
app/integrations/<source>/           어댑터 · 재시도 · 캐시 (BE가 소유)
app/api/                             주입
```

- 어댑터는 **내부 dataclass**를 반환한다. 외부 필드명이 Agent에 오지 않는다.
- 조회 실패는 **전용 예외**로 올린다. 빈 목록 반환 금지.
- 단위 테스트는 어댑터를 안 쓴다(가짜 포트). 어댑터는 **계약 테스트**를 따로 둔다: 저장해 둔 실제 응답 샘플 → 내부 dataclass 변환 검증. 스키마가 바뀌면 여기서 깨진다.
- 캐시는 `integrations` 안에 가둔다. Agent가 캐시를 알면 테스트가 시간에 의존한다.
