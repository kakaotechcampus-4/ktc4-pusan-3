# 워커 2개로 돌려 본 기록 — v1

담당: 박재형 · 작성일: 2026-11-11

> 관련: [`stateless-v1.md`](stateless-v1.md)(상태를 DB 로 옮긴 결정) · #877 · PR #899
> 운영은 `--workers 1` 그대로다. 이 문서는 "워커를 올리면 실제로 도는가" 를 로컬에서 확인한 기록이다.

## 왜 했나

PR #899 는 프로세스 메모리에 있던 상태를 PostgreSQL 로 옮기고 **서버 두 개**(별도 프로세스)로 검증했다.
한 uvicorn 이 워커 두 개를 띄우는 구성(`--workers 2`)은 돌려 본 적이 없었다. 요청이 어느 워커로 갈지
고를 수 없는 구성이라, 여러 번 보내서 "다른 워커로 간 경우" 가 실제로 섞이게 했다.

### 워커를 죽였을 때 (6번)

- uvicorn 이 약 1.5초 만에 새 워커를 띄웠다. 그 10초 동안 `/health` 40번이 전부 200 이었다 — 남은 워커가 받았다.
- 죽은 워커가 돌리던 run 은 잃는다. 저장은 0건이다(반쯤 저장되지 않는다).
- 그 run 의 SSE 는 `step` 하나를 받고 **끝 이벤트 없이** 끊겼다. 다시 열어도 `failed` 는 오지 않는다.
  run 시작 90초 뒤부터는 열자마자 닫힌다.
- 같은 키로 다시 보내면 새 run 이 뜨지 않고 **죽은 run 이 재생된다.** 실패한 run 의 키는 러너가 지우는데,
  러너가 통째로 죽어 지울 주체가 없다.
- 화면은 이 경우를 "저장됐는지 확인하지 못했어요" 로 보여 주고, 기록 탭 확인과 고쳐 쓰기(새 키)로 안내한다.

## 찾은 것

### ① 처음 보는 키가 동시에 오면 중복 저장된다

- 재현: 같은 `Idempotency-Key` · 같은 본문의 `POST /children/{cid}/inputs` 4개를 같은 순간에 보낸다.
- 결과: run 4개, `observation_food` 에 같은 관찰 4건.
- 원인: 키를 읽는 것(`recall`)과 적는 것(`remember`)이 따로다. 그 사이에 들어온 요청은 전부 "처음 보는 키" 로 통과한다.
  `apps/api/app/api/idempotency.py` 머리말의 "그 창도 재생으로 흡수된다" 는 실제와 다르다.
- 같은 워커가 받은 두 요청도 서로 다른 run 이 됐다. 워커 수 때문에 생긴 문제가 아니다 — PR #947 리뷰에서
  프로세스 하나 · 진짜 Redis 로 대조했다(김명성). 고치기 전 방식(GET 뒤 SET)은 동시 4개를 100번 보내
  100번 모두 run 이 둘 이상 떴고, 고친 방식(`SET NX`)은 동시 8개를 300번 보내 어긋난 회차가 0 이었다.
- 영향: 화면은 보내는 동안 버튼을 막아 보통 사용에서는 나오지 않는다. API 를 직접 부를 때의 구멍이다.
- 고친 것: 읽기와 쓰기를 `SET … NX EX` 한 번으로 합쳐 Redis 가 하나만 통과시킨다(PR #947 — 한 줄 입력 · 사진 읽기). 사진 읽기도 같은 구조라 같은 키가 겹치면 사진을 두 번 읽었다. 응답 전체를 재생하는 창구는 아직 읽기와 쓰기가 따로다. 그중 기록 탭 삭제 · 삭제 확정은 잠금 안에서 commit 전에 키를 적어 겹쳐도 처음 응답을 받는다(#916).

### ② 다른 워커에 붙은 SSE 를 `done` 직후 닫으면 DB 연결이 버려진다

- 재현: 워커 2개에서 SSE 가 run 을 돌리지 않는 워커에 붙었을 때, 클라이언트가 `done` 을 받자마자 연결을 닫는다
  (웹도 이렇게 닫는다).
- 결과: `sqlalchemy.pool … Exception terminating connection` 과 `CancelledError` 가 로그에 남는다.
  다른 워커로 간 7건 중 7건에서 났다. 서버가 닫을 때까지 읽으면 나지 않았다(2건 중 0건 — 표본이 작다).
- 원인(코드를 읽고 한 추정): `stream_remote` 가 `done` 을 보낸 뒤 표를 한 번 더 읽는 도중에 연결이 끊긴다.
- 영향: 동작은 맞다. 워커 1개에서는 이 경로를 타지 않아 지금 운영에는 없는 현상이다. 워커를 올릴 때 고친다.
