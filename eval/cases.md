# 골든셋 — 헤드라인 10개

테크스펙 §13-2 의 eval 케이스 10개를 지금 기능 기준으로 고정한 표다. 실제로 도는 정의는 [`cases/probes.yaml`](cases/probes.yaml) 의 `headline: N` 케이스이고, **판정 기준의 정본은 그 yaml 이다.** 이 문서는 사람이 한 번에 읽는 보기라, yaml 을 고치면 이 표도 같은 PR 에서 맞춘다.

- 실행 · 통과 기준 · 결과 읽는 법 → [`README.md`](README.md)
- 테크스펙과 기대 결과가 달라진 3 · 6 · 8 · 9번(과 2번)의 이유 → [`docs/eval/eval-v1.md` §1](../docs/eval/eval-v1.md)
- 모든 실행에 같이 걸리는 §2 불변식(근거 0행 개인화 · 알레르기 식품 · 진단 표현 · 승인 없는 일정 등) → [`docs/eval/eval-v1.md` §3-2](../docs/eval/eval-v1.md). 아래 "기대 결과" 에는 그 케이스에만 있는 것만 적는다
- 입력 문장은 전부 지어낸 것이다 (공개 저장소)

| | |
| --- | --- |
| 입력 | 1턴 "오늘 좀 안 먹었어" → 되묻기 → 2턴(답) "저녁에 브로콜리" |
| 미리 깔린 상태 | 없음 |
