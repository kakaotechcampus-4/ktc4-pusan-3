#
# 🚨 5a 결과를 보기 전에 정답을 확정하고 커밋한다. 이 결과로 방식을 다시 고르지 않는다.
#    지금까지 쓴 데이터(pairs_tune · pairs_holdout · scenarios_holdout · pairs_ambiguous ·
#    scale_tune)와 subject 가 겹치면 안 된다 (test_pairs_data.py 가 확인).
#
# 정답은 "애매한 대상의 동일성 기준 — 팀 논의"(Notion) 에서 정한 기준을 따른다.
#   same  동의어 · 오타 · 띄어쓰기 · 범위를 좁히지 않는 말
#   near  다른 대상. 원재료–가공품(A) · 넓은/좁은 개념(D) · 비슷한 활동(F) · 범위를 좁히는 말(G) 포함
#   unrelated  같은 도메인 안의 무관한 대상
# 이름만으로 구분 어려운 쌍(Memory Agent 에서 구분하기로 한 유형)은 넣지 않는다.
#
# 형식: 도메인 | 정답 | subject A | subject B
