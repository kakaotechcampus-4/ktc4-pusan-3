우리가 하는 것과 OFL
--------------------

| 우리가 하는 것                    | OFL         |
| --------------------------------- | ----------- |
| woff2 변환 · 92개 서브셋로 분할   | 허용 (수정) |
| public 저장소에 커밋              | 허용 (재배포) |
| 웹 자체 호스팅 · 임베딩           | 허용        |
| 상업적 이용                       | 허용        |

🚨 **OFL 이 요구하는 것은 하나 — 저작권 고지와 라이선스를 같이 배포하는 것이다.**
그래서 이 파일이 woff2 옆에 있어야 하고, 지우면 안 된다.
서브셋 woff2 에도 저작권(name ID 0)과 라이선스(name ID 13·14) 레코드를 넣어 둔다 —
파일 하나만 따로 받아 가도 출처와 조건을 알 수 있게. 넣는 것은 빌드 스크립트가 한다.

⚠️ **폰트 파일 자체를 유료로 팔 수 없다.** 우리는 팔지 않으므로 걸리지 않는다.
폰트를 쓴 결과물(이 서비스)을 상업적으로 쓰는 것은 허용된다.

원본 TTF 는 `apps/web/fonts-src/Hakgyoansim_NalgaeR.ttf` 에 커밋해 둔다 (1.4MB).
`apps/web/scripts/build-hakgyoansim-subset.py` 가 이 폴더의 woff2 를 다시 만든다.
